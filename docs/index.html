Port conflict

Port 5000 responded, but it is not the PayPal SaaS backend.

1. Identify what is on port 5000

lsof -i :5000
ss -tlnp | grep :5000
bash fingerprint-port.sh 5000

2. Common causes

  • macOS AirPlay Receiver — System Settings → General → AirPlay Receiver → Off
  • Another Flask/Python app — pkill -f 'python app.py'
  • Docker Registry — docker ps
  • Previous run — docker compose down

3. Move this app to a different port

# Append to .env: PORT=5001
docker compose up -d --build

Next steps

Quick start

1. Clone

git clone https://github.com/swipswaps/paypal-saas-mvp.git
cd paypal-saas-mvp

2. Install Python dependencies

python3 -m venv .venv
. .venv/bin/activate
pip install flask paypal-server-sdk python-dotenv requests Werkzeug cryptography

3. Configure environment

cp .env.example .env
# Edit: PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET, SECRET_KEY, BASE_URL.
# Optionally set PORT=5001 if 5000 is taken.

4. Register subscription plans

python setup_plans.py
# Copy PLAN_ID_BASIC / PLAN_ID_PRO into .env

5. Start

docker compose up -d --build
# or: python app.py

Open http://localhost:5000. Open /setup for diagnostics.
