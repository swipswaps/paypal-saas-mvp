Port conflict

Port 5000 responded, but it is not the PayPal SaaS backend. Some other service is listening. Choose one path below.

1. Identify what is on port 5000

lsof -i :5000
ss -tlnp | grep :5000
curl -sI http://localhost:5000/ | head -5

Or run the bundled helper (from the repo directory):

bash fingerprint-port.sh 5000

2. Common causes

  • macOS AirPlay Receiver — System Settings → General → AirDrop & Handoff → AirPlay Receiver → Off
  • Another Flask/Python app — pkill -f 'python app.py'
  • Docker Registry — docker ps then stop the container
  • Previous PayPal SaaS run — docker compose down

3. Move this app to a different port

# Append to .env:
PORT=5001
HOST=0.0.0.0

# Restart:
docker compose up -d --build

Then re-probe. The page will find the backend at http://localhost:5001.

Quick start

1. Clone

git clone https://github.com/swipswaps/paypal-saas-mvp.git
cd paypal-saas-mvp

2. Install Python dependencies

python3 -m venv .venv
. .venv/bin/activate
pip install flask paypal-server-sdk python-dotenv requests Werkzeug cryptography

3. Configure environment

cp .env.example .env
# Edit .env: PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET, SECRET_KEY, BASE_URL
# Optionally set PORT=5001 if 5000 is taken.

4. Register subscription plans

python setup_plans.py
# Copy PLAN_ID_BASIC / PLAN_ID_PRO into .env

5. Start

docker compose up -d --build
# or: python app.py

Open http://localhost:5000 (or whichever PORT you set).

Where the monthly fees come from

Prices exist in two places: setup_plans.py registers them with PayPal (fixed_price), and app.py's PLANS dict displays them (now driven by TIER_*_PRICE env vars). PayPal charges the buyer monthly; the app records webhooks. To change prices, use the config builder above, re-run setup_plans.py, copy the new PLAN_ID_*, and rebuild.
