Quick start

1. Clone

git clone https://github.com/swipswaps/paypal-saas-mvp.git
cd paypal-saas-mvp

2. Install Python dependencies

python3 -m venv .venv
. .venv/bin/activate
pip install flask paypal-server-sdk python-dotenv requests Werkzeug cryptography

Skip this only if you will use Docker exclusively. This step is what prevents python setup_plans.py from failing with ModuleNotFoundError: requests or a broken urllib3 import.

3. Configure environment

cp .env.example .env
# Edit .env and fill in:
#   PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET  -> https://developer.paypal.com/dashboard/applications
#   SECRET_KEY                              -> long random string
#   BASE_URL                                -> your ngrok static HTTPS URL (step 5)
# Enable "Catalog" and "Subscriptions" scopes on the PayPal app.

4. Register subscription plans

python setup_plans.py
# Copy the printed PLAN_ID_BASIC and PLAN_ID_PRO into .env

5. Expose webhooks with ngrok

# Claim a free static domain at:
#   https://dashboard.ngrok.com/cloud-edge/domains
ngrok http --domain=your-static-name.ngrok-free.app 5000

Set BASE_URL in .env to that HTTPS URL. In the PayPal Developer Dashboard, add a webhook https://your-static-name.ngrok-free.app/webhook, subscribe to BILLING.SUBSCRIPTION.* and PAYMENT.SALE.COMPLETED, and put the resulting webhook ID into WEBHOOK_ID in .env.

6. Launch

# Docker (recommended):
docker compose up -d --build

# Local Python (venv activated):
python app.py

App runs at http://localhost:5000.

7. Test the flow

Open http://localhost:5000, register a user, subscribe to a tier, approve in the PayPal sandbox, then inspect /events.

What is included

  • Flask app: register, login, dashboard, gated premium page
  • PayPal Server SDK subscription creation and cancellation
  • Webhook handler with cryptographic self-verification (CRC32 + RSA)
  • SQLite in WAL mode with idempotent event logging
  • Docker + docker-compose; Proxmox LXC guidance in install.py
  • Audited fixes vs. the NeuralNine tutorial: correct import paths, OAuth parameter names, raw-body webhook verification

Troubleshooting

SymptomFix
ModuleNotFoundError: paypal_server_sdk The package is paypalserversdk (no underscores). The client class is PaypalServersdkClient.
ModuleNotFoundError: requests Run step 2 above (venv + pip install). Then re-run python setup_plans.py.
401 on every API call Use o_auth_client_id / o_auth_client_secret, not oath_*.
Webhook 400 Invalid signature Read request.get_data() first; verify raw bytes with CRC32 + RSA. Do not re-serialize parsed JSON.
database is locked WAL mode is enabled. Keep timeout=15 on connections.
is a directory (Docker) Run touch saas_shop.db before docker compose up.
setup_plans.py 401/403 Enable Catalog + Subscriptions scopes for the PayPal app.
