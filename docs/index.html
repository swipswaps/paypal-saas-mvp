PayPal SaaS Subscription MVP

This GitHub Pages site is a static landing page. The Flask application and webhook listener run in Docker or a Proxmox LXC container; they cannot run on GitHub Pages.

Run the app

git clone https://github.com/<owner>/paypal-saas-mvp.git
cd paypal-saas-mvp
cp .env.example .env
python setup_plans.py
docker compose up --build -d

See the repository README.txt for the full guide.
